# WTFM

**Write the F***ing Manual.** A plugin for your coding agent that writes the user docs.
Screenshots included.

Ask Claude Code for a guide and it reads your source, writes the steps in plain
language, and shows every screen with a screenshot rendered from your real templates
and CSS. No running app, no manual captures, no account.

This is the plugin build of [SupportPages-io/wtfm](https://github.com/SupportPages-io/wtfm),
generated by its release workflow. Source, issues and the full documentation live there.

## Install

In Claude Code 2.1.275 or later:

```text
/plugin install wtfm --marketplace SupportPages-io/wtfm
```

In earlier versions:

```text
/plugin marketplace add SupportPages-io/wtfm
/plugin install wtfm@supportpages
```

**You'll need** macOS or Linux (on Windows, use WSL), Git, and Node.js 22.12 or later
on your `PATH`. Chromium for screenshots downloads in the background the first time
a session starts.

## Quick start

Open Claude Code in your product's folder and ask:

> Set up WTFM for this project.

Then ask for an article in plain words:

> Write an illustrated guide to inviting a teammate.

A few minutes later the article is in your project as an `index.md` with its
screenshots beside it.
