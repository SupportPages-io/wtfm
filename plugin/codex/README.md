# WTFM

**Write the F***ing Manual.** A plugin for your coding agent that writes the user docs.
Screenshots included.

Ask Codex for a guide and it reads your source, writes the steps in plain language,
and shows every screen with a screenshot rendered from your real templates and CSS.
No running app, no manual captures, no account.

This is the Codex plugin build of [SupportPages-io/wtfm](https://github.com/SupportPages-io/wtfm),
generated by its release workflow. Source, issues and the full documentation live there.

## Install

```sh
codex plugin marketplace add SupportPages-io/wtfm
codex plugin add wtfm@supportpages
```

Then start a new Codex session. To update, run `codex plugin add wtfm@supportpages`
again.

**You'll need** macOS or Linux (on Windows, use WSL), Git, and Node.js 22.12 or later
with npm on your `PATH`. The first time the plugin starts, it installs its npm packages
without running their install scripts, and Chromium for screenshots downloads in the
background. Codex asks you to review the plugin's two hooks in `/hooks` before they
run; WTFM works without them.

## Quick start

Open Codex in your product's folder and ask:

> Set up WTFM for this project.

Then ask for an article in plain words:

> Write an illustrated guide to inviting a teammate.

A few minutes later the article is in your project as an `index.md` with its
screenshots beside it.
